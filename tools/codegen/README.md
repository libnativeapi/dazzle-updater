# codegen

Generates the dazzle updater C ABI and the Rust, Dart, C# and Go bindings from the public C++
headers in `core/src/`. The C++ headers are the source of truth: change them, then
regenerate. Never edit a file that starts with
`// AUTO-GENERATED by tools/codegen. DO NOT EDIT.`

```bash
./codegen          # regenerate every file
./codegen check    # CI: exit non-zero if any generated file is out of date or stale
```

## Requirements

- Python 3.9+ (standard library only)
- `clang++` — the headers are read through clang's JSON AST dump; set `CLANG` to use
  another binary
- `rustfmt`, `dart` and `gofmt` — the generated bindings use their language formatters, so
  formatting a binding never touches its generated files

## What it reads

The headers listed in `API_HEADERS` in [main.py](main.py).
Add a new module's header there.

From each header it takes the classes in `namespace dazzle_updater` that are **singletons** (a
`static T& GetInstance()`), and from them every public, non-static method whose types
are supported:

| C++ | C | Rust | Dart | C# | Go |
| --- | --- | --- | --- | --- | --- |
| `void` | `void` | `()` | `void` | `void` | no result |
| `bool` | `bool` | `bool` | `bool` | `bool` | `bool` |
| `int`, `int32_t` | `int32_t` | `i32` | `int` | `int` | `int32` |
| `int64_t` | `int64_t` | `i64` | `int` | `long` | `int64` |
| `double` | `double` | `f64` | `double` | `double` | `float64` |
| `const std::string&` (in) | `const char*` | `&str` | `String` | `string` | `string` |
| `std::string` (out) | `char*`, NULL when empty | `Option<String>` | `String?` | `string?` | `string`, empty for NULL |

Anything else is **skipped with a warning** naming the method, never silently dropped.
Constructors, operators, deleted members and nested classes are ignored.

## What it writes

| File | Contents |
| --- | --- |
| `core/src/capi/<module>_c.h`, `.cpp` | `dazzle_<module>_<method>` functions; each catches exceptions |
| `core/include/dazzle_updater.h` | The umbrella header |
| `bindings/rust/src/ffi.rs` | `extern "C"` declarations |
| `bindings/rust/src/<module>.rs` | The safe wrapper struct |
| `bindings/rust/src/modules.rs` | `mod` + `pub use` per class, `include!`d by `lib.rs` |
| `bindings/dart/lib/src/dazzle_updater_bindings.dart` | `@Native` declarations |
| `bindings/dart/lib/src/<module>.dart` | The wrapper class |
| `bindings/dart/lib/dazzle_updater.dart` | The package entry file: one export per class |
| `bindings/csharp/src/NativeMethods.cs` | `LibraryImport` declarations |
| `bindings/csharp/src/<Class>.cs` | The wrapper class |
| `bindings/go/<module>.go` | The wrapper type and cgo calls to the C ABI |

A generated file that the headers no longer produce (a removed class) is deleted by
`./codegen` and reported by `./codegen check`.

Hand-written files the generated code builds on are never touched: `common_c.h` and
`string_utils_c.*` in the C ABI, and each binding's string helpers (`ffi_string.rs`,
`ffi_string.dart`, `CString.cs`, `ffi_string.go`), Rust's `lib.rs` and Go's `native.go`.

## Naming

- **Properties.** A `GetX() const` (or `bool IsX() const`) paired with `SetX(value)` of
  the same type becomes a property: Rust `x()` / `set_x()`, Dart `x` getter and setter,
  C# `X { get; set; }`, Go `X()` / `SetX()`. `IsX` keeps its prefix: `is_x()`, `isX`, `IsX`. A getter without
  a setter is read-only.
- **Actions.** Every other method: Rust `snake_case()`, Dart `camelCase()`, C#/Go
  `PascalCase()`.
- **Instance.** Rust `Class::instance()`, Dart `Class.instance`, C# `Class.Instance`,
  Go `ClassInstance()`.
- **Go initialisms.** Exported names preserve common initialisms, e.g. `URL()`,
  `SetURL()` and `UpdateReleaseNotesURL()`.

## Doc comments

The Doxygen comment of each class and method is carried into every binding: `@brief`
and body paragraphs, `@param`, `@return` and `@note` (such as the platform availability
block). `@code` blocks hold C++ and are dropped, together with a lead-in line ending in
`:`. References like `SetSource()` are renamed to the binding's name for that member.

## Layout

```
tools/codegen/
├── main.py         # entry point, API_HEADERS, file layout, formatting, check
├── parser.py       # clang AST -> model
├── model.py        # Class / Method / Property, naming helpers
├── docs.py         # Doxygen -> doc paragraphs
├── emit_c.py       # C ABI and umbrella header
├── emit_rust.py
├── emit_dart.py
├── emit_csharp.py
└── emit_go.py
```
